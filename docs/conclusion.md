## 2. 핵심 결과
1. **설계 변경이 기체 응답을 바꾼다 (E0, 1D 맵).** 같은 명령에서 수직 가속도는 B가 A보다 +0.58%, C가 −2.26%다. 피치 각가속도는 B +0.34%, C −1.30%다. 이 값은 손계산과 1e-9 안에서 일치한다.
2. **E1/E2.** 엔진 질량 차이(최대 1.9 kg, 기체의 0.16%)는 작아서 E1(질량 고정)과 E2(질량 포함)의 연료 차이는 0.11 kg 이하다. 추력 맵 차이가 지배적이다. bell_C는 호버와 착륙 모두 맵 invalid 구간(분리 위험)을 써서 `physics_valid=false`다.
3. **CFD (G1).** 3격자 GCI는 0.09–0.14%다. conical_A의 CFD 추력은 1D보다 0.37% 낮다. bell_B는 1D보다 1.88% 낮아 conical_A보다 오히려 1.3% 낮다. 1D의 벨 효율 가정(λ = 0.985)이 이 윤곽(80% 포물선, θn 22°, θe 12°)에는 맞지 않는다. 벨이 원추보다 낫다는 통념을 이 설계에 그대로 옮기면 안 된다는 것이 이번 CFD의 실질적인 발견이다.
4. **CFD 맵 주입.** CFD 맵으로 바꿔도 PD 착륙은 A/B 모두 30/30을 유지했다. B는 평균 연료가 79.47 kg으로 1D 맵(78.69 kg)보다 1.0% 늘었다. 추력 감소가 비행 결과로 이어진다.
5. **내고장성.** RCS 1개 고장에서 19/30이던 것을 할당기 수정으로 30/30(인지·미인지 모두)으로 올렸다. 2개 고장(+롤 권한 상실)은 고장을 알면 30/30, 모르면 19/30이다.

## 5. 실패 요인과 OOD 위험
- 고장 검출이 없으면 롤 권한 상실 시 착륙이 37% 실패한다.
- 평가 분포가 학습·튜닝 분포와 같다. 고도 40–80 m, 수평 8 m, 바람 300 N 밖은 시험하지 않았다.
- 1D 분리 기준(0.4)에 따라 bell_C 판정이 바뀐다(0.25면 호버 유효).
- 비점성 CFD는 경계층·분리·열손실을 반영하지 않는다. 실제 추력은 더 낮을 수 있다.
- 공력, 센서 노이즈·지연, 추진제 슬로싱, jet damping을 넣지 않았다(ADR-0004).
