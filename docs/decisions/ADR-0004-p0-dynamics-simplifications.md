# ADR-0004 P0 동역학 단순화

- 상태: 채택 (P0 한정, 각 항목은 플래그 또는 후속 실험으로 해제)

| 단순화 | 이유 | 해제 조건 |
|---|---|---|
| 공력 없음 (`aero_model_id: none_v0`) | 저속 VTVL hop, 공력 모델 근거 없음 | 착륙 속도 범위의 항력·모멘트 모델과 출처 확보 |
| jet damping, İ 항, CoM 이동률 항 생략 | 저속·저회전 hop에서 작다고 추정 (INFERRED; NASA TR R-115는 피치/요 jet damping이 일반적으로 크다고 함) | RocketPy 1.13(해당 항 포함)과 같은 조건 비교로 크기 정량화 |
| 추진제는 탱크 바닥부터 채운 강체 원기둥, 슬로싱 없음 | 질량·CoM·관성 변화의 1차 효과만 필요 | 슬로싱 모델 필요성 확인 시 |
| 엔진은 점질량 2개(본체 + 노즐 셸), 자체 관성 무시 | 노즐 질량 수 kg 수준 | 짐벌 관성 토크가 제어에 영향 줄 때 |
| 착지 접촉은 다리별 스프링-댐퍼 + 정규화 쿨롱 마찰 | 참조 모델용 | Isaac 접촉과 비교 |
| 스로틀은 Pc 비례, Tc 고정 | 이상기체 가정 | CEA 연결 시 |
| 제어기는 참값 상태 사용 | P0는 물리 검증 단계 | 센서 노이즈·지연 모델 추가 시 |
