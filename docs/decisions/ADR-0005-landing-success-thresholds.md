# ADR-0005 착륙 성공 판정 (잠정)

- 상태: **잠정**. 설계안 11장은 첫 실험 전에 임무 크기에 맞춰 합의하라고 요구한다. G4 비교 전에 사용자 확인 필요.

`evaluation/simulate.py::LANDING_LIMITS`
- 첫 접촉 시 수직속도 |vz| ≤ 2.0 m/s, 수평속도 ≤ 1.0 m/s, 기울기 ≤ 10°
- 패드 중심 대비 CoM 수평 오차 ≤ 2.0 m
- 접촉 3 s 후 기울기 ≤ 15° (전도 아님)
- 첫 접촉 순간 엔진 차단 (단순 규칙)

추가 규칙: 성능 맵의 invalid 셀(분리 위험 등)을 한 스텝이라도 쓴 에피소드는 `physics_valid=false`로 표시하고, 보고서에서 "성공"과 "성공이면서 물리적으로 유효"를 따로 센다.
