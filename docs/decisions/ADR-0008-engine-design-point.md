# ADR-0008 가상 엔진 설계점 (A/B/C)

- 상태: 채택

설계안은 수치를 정하지 않았다. 가상 VTVL(습윤 질량 약 1.21 t)에서 해면 호버(스로틀 약 0.6)가 분리 위험 없이 가능해야 한다는 조건으로 정했다.

- 공통: At = 5.6e-3 m², Pc = 2.5 MPa, Tc = 3000 K, γ = 1.2, M = 22 g/mol (가상 고온가스, 특정 추진제 아님), 스로틀 0.4–1.0.
- conical_A: ε = 3.5, 반각 15°.
- bell_B: ε = 3.5, 80% Rao 포물선 벨, θn 22°, θe 12°, λ = 0.985 (가정값, 1차 출처 미확인).
- bell_C: ε = 6.0, 80% 벨, θn 25°, θe 10°. 해면에서 스로틀 약 0.65 이하면 Pe/Pa < 0.4가 되어 맵이 invalid가 된다. "넓은 노즐이 저고도 저스로틀에서 맵 유효 범위를 벗어난다"를 일부러 드러내는 설계다.

처음 시도한 ε = 6/12, Pc = 2 MPa 조합은 A조차 호버 스로틀에서 분리 위험이라 버렸다.
